# Code of Conduct / 行为准则

## Our commitment / 我们的承诺

We want CodexRelay to be a welcoming, respectful, and technically focused project for everyone. Participants are expected to contribute in good faith and to treat one another with patience and professionalism.

我们希望 CodexRelay 成为一个友好、尊重他人、专注技术的项目。参与者应当善意交流，以耐心和专业的方式对待彼此。

## Expected behavior / 建议行为

- Use welcoming and inclusive language.
- Focus criticism on ideas, behavior, and evidence rather than people.
- Accept differing viewpoints and respond constructively.
- Keep private information, credentials, and proprietary code out of public discussions.

- 使用友好、包容的语言；
- 针对想法、行为和证据进行讨论，不针对个人；
- 尊重不同观点，并以建设性的方式回应；
- 不在公开讨论中发布私人信息、凭据或专有代码。

## Unacceptable behavior / 不可接受的行为

Harassment, discrimination, threats, personal attacks, deliberate exposure of private information, and disruptive behavior are not tolerated.

骚扰、歧视、威胁、人身攻击、故意泄露私人信息以及持续扰乱讨论的行为均不可接受。

## Enforcement / 执行

Report concerns privately to the project maintainer through the contact channel listed in the repository profile. Do not open a public Issue for a security report. Maintainers may edit, hide, or remove contributions that violate this code and may restrict participation when necessary.

如需报告问题，请通过仓库主页列出的联系方式私下联系维护者。安全问题不要提交到公开 Issue。维护者可以编辑、隐藏或删除违反本准则的内容，并在必要时限制相关参与者继续参与项目。
